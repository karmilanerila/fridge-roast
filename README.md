One line roasting a smart fridge, written by `main.py` to `/output/entry.txt`.

The roast aims at the fridge's firmware and its ice maker: the machine refuses
to make ice until its owner installs a firmware update and accepts the terms —
so the cubes are held hostage by a EULA.

Run it with:

```sh
python3 main.py
```

It writes exactly one line (126 characters) to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`), stdlib only, deterministic.
